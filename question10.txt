cd client-app
git init
echo "yo" >> index.html
echo "yo" >> app.js
git add index.html app.js
git commit -m "Initial client files"
git remote add origin https://github.com/startup/client-app.git
git push origin main 
git log

1. Navigated into the client-app directory.
2. Then, initialized git inside it using git init command.
3. Appended "yo" inside both the index.html and app.js using the echo command.
4. Then, stagged both of the files using git add command.
5. Commited bith the files with "Initial client files" using git commit -m command.
6. Then, registered the link with origin using git remote add origin command.
7. Pushed all the commits from origin to main through git puch origin main command.
8. Finally, checked all the commits using the gut log command.
